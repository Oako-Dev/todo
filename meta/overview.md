## What It Does

This is a shared todo list application. Users can create a new todo list and receive a unique shareable link. Each list allows users to add, edit, remove, and mark todo items as complete. All changes are persisted on the server and automatically synced across sessions.

## Who It's For

Anyone who needs to organize tasks or collaborate on a shared todo list via a browser.
