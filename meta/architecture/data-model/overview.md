## TodoList

A **TodoList** is the primary entity in the system. Each TodoList has:
- `id` (string): Unique identifier, generated by the client (currently a random 16-character string)
- `list` (array of TodoListItem): An ordered collection of items in the list

TodoLists are stored in DynamoDB with `id` as the primary key. The list is immutable on the server side — updates always replace the entire list.

## TodoListItem

A **TodoListItem** is a single task within a TodoList. Each item has:
- `text` (string): The task description
- `completed` (boolean): Whether the task has been marked as done

The order of items in the list is significant and is preserved during updates.
